# 汤姆AI女团 · Skill

> 真人 AI 女团 MV / 舞台表演 / 齐舞 / 成员展示工作流

**版本：1.0**

「汤姆AI女团 · Skill」是一套面向真人 AI 女团视频生成的完整提示词与导演规则系统。  
它的重点不是简单生成“几名女生一起跳舞”，而是解决多人 AI 视频里最常见的连续性问题：

- 成员换脸
- 成员数量变化
- 发型、服装互换
- 左右站位错乱
- 换位瞬移
- 多人动作穿模
- 舞台结构漂移
- 多镜头人物身份不一致
- AI 塑料皮肤与过度磨皮

## 适用场景

- 真人 AI 女团 MV
- K-POP 风格舞台视频
- 多人齐舞
- 女团成员展示
- C 位爆发镜头
- 阵型变化与换位
- 多镜头连续舞台表演

## 核心设计理念

### 1. 每名成员必须拥有独立身份

成员使用 A / B / C / D / E 等编号独立管理。

不使用“五名女生”“全员”等模糊描述替代关键站位。

### 2. 先锁定，再变化

先锁定：

- 人脸
- 五官
- 发型
- 服装
- 配饰
- 身材比例
- 成员数量
- 舞台结构

之后才允许改变：

- 动作
- 表情
- 朝向
- 阵型
- 摄影机
- 景别
- 灯光

### 3. 所有换位必须存在真实过程

任何阵型变化都必须明确：

`起始位置 → 迈步 → 交叉/错位移动 → 目标位置 → 新阵型`

禁止成员突然交换位置、穿过其他成员身体或镜头切换后左右关系错误。

### 4. 每个镜头必须回答四个问题

- 谁在哪里？
- 谁在做什么？
- 摄影机在拍谁？
- 下一秒她移动到哪里？

只有这些关系清晰，才输出最终视频 Prompt。

## 默认 30 秒 MV 结构

| 镜头 | 时间 | 功能 | 能量 |
|---|---:|---|---:|
| 01 | 0–5s | 登场 / 建立阵型 | 40→60% |
| 02 | 5–10s | 成员展示 | 70% |
| 03 | 10–15s | 组合 / 第一次换位 | 75–80% |
| 04 | 15–20s | 齐舞高潮 | 90% |
| 05 | 20–25s | C 位爆发 | 100% |
| 06 | 25–30s | Ending Pose | 50–60% |

如果用户指定其他时长，则按目标时长重新设计。

## 使用方法

把 [`SKILL.md`](./SKILL.md) 中的完整规则交给你使用的 AI Agent / 大模型，并提供成员参考、服装、舞台和风格需求。

示例输入：

```text
成员数量：5人
成员参考：@成员A @成员B @成员C @成员D @成员E
服装：@服装参考
舞台：@舞台参考
时长：15秒
比例：16:9
风格：真人KPOP女团舞台MV，冷黑蓝紫灯光，强节奏齐舞。
要求：C为中心成员，第二镜发生B与D换位，所有换位必须有真实移动过程。
```

Skill 会先完成身份、妆造和舞台锁定，再进行站位、动作、摄影机与分镜设计。
