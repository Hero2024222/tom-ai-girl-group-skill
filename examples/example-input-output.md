# 示例：5人女团 15 秒舞台 MV

## 输入

```text
成员数量：5人

成员参考：
@成员A
@成员B
@成员C
@成员D
@成员E

服装资产：
@服装参考

舞台：
@舞台参考

时长：
15秒

比例：
16:9

风格：
真人KPOP女团专业舞台MV，黑银镭射服装，冷黑蓝紫色舞台，
镜面地面，节奏强烈，真实数字电影摄影质感。

要求：
成员C为中心成员。
第二段发生B与D换位。
换位必须出现真实迈步过程。
禁止成员换脸、串位、服装互换、复制或消失。
```

## 推荐执行顺序

1. 建立 A / B / C / D / E 五名成员独立档案。
2. 锁定五人的人脸、发型、服装、鞋子和配饰。
3. 锁定舞台结构。
4. 建立初始一字横排阵型。
5. 设计 3 个 5 秒镜头。
6. 第二镜明确写出 B 与 D 的移动路径。
7. 每镜分别生成可直接用于视频模型的 Prompt。
8. 最后运行一致性检查清单。

## 简化分镜示例

### 镜头01｜0–5秒

- 阵型：A — B — C — D — E
- C：画面中心，向前半步，抬头进入主动作
- A/E：外侧保持较小幅度动作
- B/D：向内侧轻微转身
- 摄影机：正面低机位缓慢推进
- 结束：五人形成稳定正面 Pose

### 镜头02｜5–10秒

- C：保持中心位置执行核心手臂动作
- B：从画面左中向右后方迈步
- D：从画面右中向左后方迈步
- 两人通过前后错层完成换位，禁止身体穿插
- A/E：保持最外侧位置
- 摄影机：轻微横向跟随C，不改变五人身份关系

### 镜头03｜10–15秒

- 新阵型稳定
- 五人进入严格同步齐舞
- C完成最后一次核心动作
- 摄影机快速拉远展示完整阵型
- 最后一拍全员定格 Ending Pose
